# Sistema de Helpdesk & Gestão de TI Escolar

Aplicação desenvolvida em Python e SQLite para registro, priorização e controle de manutenção de equipamentos de informática em ambientes de ensino (laboratórios, salas de aula e infraestrutura).

## Funcionalidades
- Cadastro de chamados técnicos com local, equipamento e nível de prioridade.
- Persistência de dados em banco de dados SQLite local.
- Atualização do status do ticket (Pendente / Concluído).
- Registro automático do timestamp de abertura dos chamados.

## Tecnologias
- Python 3.x
- SQLite3
